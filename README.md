# Pulse

Портфолио-проект: сервис мониторинга доступности сайтов с реальными HTTP-проверками, графиками времени ответа и историей инцидентов.

**Стек:** React, TypeScript, Vinext / Vite, Cloudflare Workers.

- Добавление, приостановка и удаление мониторов.
- Серверная проверка HTTP(S) с таймаутом и обработкой перенаправлений.
- История до 288 проверок на сайт, фильтры и экспорт JSON.
- Адаптивный интерфейс, демонстрационные данные явно помечены.

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173. Сборка: `npm run build`; запуск сборки: `npm start`.

Проверки выполняются раз в минуту, пока открыта страница; история хранится в localStorage. Это MVP, без аккаунтов, фонового планировщика и уведомлений. Для публичного многопользовательского сервиса нужны база данных, планировщик, квоты и DNS-проверки исходящих запросов.
